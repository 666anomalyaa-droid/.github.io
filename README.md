# H-Rua!! Official Profile

> **デザインテーマ**：ブラック・クリムゾン・ゴールド・シルバーを中心にしたラグジュアリーカジノ風。金色の粒子、時折横切るライトストリーク、短い亀裂フラッシュ、スクロール表示演出を搭載。OSの「視差効果を減らす」設定にも配慮しています。


VS Codeで編集できる、名刺・履歴書風のレスポンシブ個人サイトです。
プロフィール、SNSリンク、お知らせ、横スクロールギャラリー、訪問者コメント欄を用意しています。

## 1. まず編集する場所

### `js/site-data.js`

名前・プロフィール・資格・経歴・スキル・SNSリンク・ギャラリーの内容は、基本的にこのファイルを編集します。

- `YOUR NAME`：自分の名前に変更
- `nameEn`：ローマ字表記
- `catchcopy`：トップページの短い紹介文
- `about`：自己紹介
- `details`：プロフィール欄の項目
- `career`：学歴・経歴
- `certificates`：資格
- `skills`：スキル・好きなこと
- `socialLinks`：Instagram、X、YouTubeなどのURL
- `gallery`：写真・出来事の一覧

項目を追加したい場合は、同じ形の `{ ... }` をコピーして追加してください。項目と項目の間のカンマ `,` を忘れないようにします。

### 写真の変更
現在のプロフィール画像は `assets/h-rua-profile.png` に設定済みです。差し替える場合は同じフォルダに画像を置き、`js/site-data.js` の `profile.image` を変更してください。



1. 自分の画像ファイルを `assets` フォルダへ入れる
2. `js/site-data.js` の `profile.image` を例のように変更する
   - `image: "assets/my-photo.jpg"`
3. ギャラリーも同じく `gallery` の `image` を変更する

画像ファイル名は半角英数字がおすすめです。公開サイトに載せてもよい写真だけを使ってください。

### 色の変更

`css/style.css` の末尾にある `H-Rua!! LUXURY CRIMSON EDITION` セクションで、ブラック・クリムゾン・ゴールド・シルバーの色を調整できます。

- `--navy`：メインの濃紺
- `--accent`：アクセントカラー
- `--gold`：サブカラー
- `--paper`：明るい背景色

## 3. お知らせ・コメントをオンラインで使う（Supabase設定）

お知らせと訪問者コメントは、インターネット上で保存するためにSupabaseを使います。DB設定が終わるまでは、トップページのプロフィール等だけが動き、コメント投稿は停止状態になります。

### A. Supabaseプロジェクトを作る

1. https://supabase.com/ でアカウントを作成・ログイン
2. 新しいプロジェクトを作成
3. プロジェクトの Project URL と Publishable key（または従来の anon public key）を確認
4. `js/config.js` に貼り付ける

```js
window.SITE_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT_ID.supabase.co",
  supabaseAnonKey: "YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY"
};
```

**重要：** ブラウザへ置いてよいのはPublishable key / anon public keyです。`secret` keyや`service_role` keyは絶対にHTML・JavaScriptへ書かないでください。公開用キーを使う場合も、次のRLS設定が必須です。

### B. SQLを実行する

1. Supabaseのプロジェクト画面で「SQL Editor」を開く
2. `sql/setup.sql` の中身をすべて貼り付ける
3. Run（実行）を押す

これで、お知らせ・訪問者コメント・管理者一覧のテーブルとアクセス制御が作られます。

### C. 管理者アカウントを作る

1. Supabaseの「Authentication」→「Users」で、管理画面に使うユーザーを作成する（メールアドレス・パスワードを設定）
2. 作成したユーザーのID（UUID）をコピーする
3. SQL Editorで次のSQLを実行する。メールアドレスとユーザーIDは自分のものに差し替える

```sql
insert into public.site_admins (user_id)
select id
from auth.users
where email = '自分の管理者メールアドレス';
```

4. `https://自分のサイトURL/admin.html` を開いて、そのメールアドレスとパスワードでログインする

**注意：** Authenticationにユーザーを作っただけでは管理者になりません。必ず `site_admins` テーブルへ登録してください。管理者として登録されていないユーザーは、ログインできても投稿・承認・削除できません。

### D. コメントの運用

- 訪問者は名前とメッセージを送信
- 送信直後のコメントは `pending`（承認待ち）として保存
- 管理画面で「承認する」を押す
- `approved` になったコメントだけがトップページに表示される
- 不適切な投稿は管理画面から削除

## 4. インターネットへ公開する（GitHub Pages）

GitHub PagesはHTML/CSS/JavaScriptなどの静的ファイルを公開できます。以下は一般的な流れです。

1. GitHubアカウントを作る（またはログイン）
2. 新しいPublicリポジトリを作成する（例：`yourname.github.io`）
3. このフォルダの中身をリポジトリの一番上にアップロードする
4. リポジトリの「Settings」→「Pages」を開く
5. Build and deployment の Source で「Deploy from a branch」を選ぶ
6. Branchを `main`、Folderを `/(root)` にして Save
7. 公開URLが表示されたらアクセスする

GitHub Pagesの公開サイトはインターネット上で誰でも閲覧できます。リポジトリにアップした写真・プロフィール・コードも公開される前提で、個人情報や秘密情報を入れないでください。

## 6. 仕様・注意点

- トップページはスマホ・タブレット・PCに対応するレスポンシブデザインです。
- ギャラリーは横スクロールと左右ボタンに対応しています。
- お知らせ・コメントはSupabaseに保存され、サイトを閉じても残ります。
- コメントは承認制です。公開前に管理者が内容を確認できます。
- 管理者画面のURLを知っているだけでは管理操作できません。ログインとDB側の管理者権限が必要です。
- 公開コメント欄はスパム投稿の対象になる可能性があります。運用を始める前に、必要に応じてCAPTCHAや投稿頻度制限を追加してください。
- サイトの閲覧者に個人情報（住所、電話番号、学校の詳細、個人的なメール等）を公開しすぎないよう注意してください。

## 5. スロット・エントランス（トップページ前の演出）

トップページを開くと、最初にスロットゲートが表示されます。

- 「TAP TO SPIN」を押すと3つのリールが回転します。
- 1回ごとに90%で777、10%で777以外の数字が出ます。
- 777なら「ENTER PROFILE」が表示され、押すと左右のゲートが開いてプロフィールが表示されます。
- ハズレの場合は「TRY AGAIN」で何度でも再挑戦できます。
- お金・課金・ポイントなどは一切使用しない演出です。
- OSで「視差効果を減らす」が有効な場合は、回転時間を短縮して動きを控えめにします。

### 画像の変更
スロットの背景画像は `assets/slot-gate.jpg` です。別画像へ差し替える場合は同名で上書きしてください。

### 当たり確率の変更
`js/slot-gate.js` の `Math.random() < 0.90` の `0.90` が当たり確率です。例えば `0.80` にすると80%になります。

## 管理ダッシュボード：リンク公開／非公開

1. Supabase Dashboard → SQL Editorを開きます。
2. `sql/link-settings-migration.sql` の内容を貼り付けて1回実行します。
3. `admin.html` に管理者ログインします。

非公開のリンクは、プロフィール画面でリンク先へ移動できなくなり、アイコンの代わりに鍵マークが表示されます。Steamのフレンドコードコピー操作も非公開中は表示しません。

## スロットゲート：4桁コードとコイン

- 初期コード：`0000`
- 設定ファイル：`js/slot-gate.js`
- 変更箇所：`const ENTRY_PASSCODE = "0000";`
- 正しい4桁コードを入力するとコインが登場し、スロットを回せるようになります。

**セキュリティ上の注意：** GitHub Pagesは静的サイトです。`js/slot-gate.js` に置いた4桁コードは、公開されたJavaScriptソースから閲覧者が確認できるため、この機能は入場演出用です。本当に特定の人だけにサイトを見せたい場合は、サーバー側認証やCloudflare Accessなどのホスティング側アクセス制御が別途必要です。また、リンクの非公開切り替えは画面上の表示・クリック制御であり、URL自体の秘匿を保証するものではありません。
